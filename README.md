# Weather
Finds the best 2-hour window today for running, cycling, picnics, stargazing, laundry, spraying and drying crops. Works for cities, towns and villages, with a farm advisor.

    python -m venv venv
    venv\Scripts\activate        (Mac/Linux: source venv/bin/activate)
    pip install -r requirements.txt
    python app.py                -> open http://127.0.0.1:5000
